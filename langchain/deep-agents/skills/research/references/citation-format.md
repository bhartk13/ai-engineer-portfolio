# Citation format

Use inline markdown links tied to search results:

```markdown
Multi-agent adoption is accelerating in enterprise settings [Gartner AI Trends 2026](https://example.com/report).
```

Rules:

1. Every bullet in **Executive summary** and **Key findings** must include ≥1 citation.
2. Prefer primary sources (official docs, papers, vendor blogs) over aggregators.
3. End with a **Sources** table:

| # | Title | URL | Used for |
|---|-------|-----|----------|
| 1 | ... | ... | Theme / claim |

4. Do not invent URLs — only cite URLs returned by `internet_search` or provided by the user.
