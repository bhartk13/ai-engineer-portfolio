# Python checklist (before save)

- [ ] One definition per function/class/`main`
- [ ] `if __name__ == "__main__":` appears at most once
- [ ] Secrets from `os.getenv`, not hardcoded
- [ ] Basic error handling for I/O and network calls
- [ ] Module docstring or top comment if non-trivial
- [ ] Runnable as script when user expects CLI behavior
